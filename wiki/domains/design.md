# Design

Visual and UX language for **Kabanchik**. Source: [[sources/design-brief]], [[sources/google-stitch-prompts]], [[sources/kabanchik-ui-plan]].

## Posture

Light, polished B2B SaaS. Calm, trustworthy, operational. Clean enterprise UX with a subtle modern edge. Premium, not flashy.

## Typography

- **Inter** throughout.
- Strong page titles, compact labels, body 13–14px.
- Tight but breathable spacing, moderate density.

## Color tokens

| Role | Value |
|---|---|
| App background | `#f3f4f6` |
| Card / panel | `#ffffff` |
| Primary text | `#111827` |
| Secondary text | `#6b7280` |
| Muted text | `#9ca3af` |
| Primary accent / CTA | `#6366f1` (indigo) |
| Primary hover | `#4f46e5` |
| Active nav background | `#eef2ff` |
| Border | `#e5e7eb` |

### Semantic status

- Pending — neutral gray
- Processing — amber
- Transcribing — violet
- Analyzing — blue
- Done / Connected / Success — green
- Error / Danger — red

## Components

- 8–12px radii, thin borders, subtle shadows.
- Pills, badges, tabs, segmented filters, lightweight tables.
- Avatar circles, status chips, accordions, split panes, diff cards, wizard steps.

## Navigation

- **Pre-project** screens — top bar.
- **Project-level** screens — fixed left sidebar (~240px) with project switcher; nav items: Chat, Meetings, Updates, Agent Trace, Settings; user footer.

## Layout

Desktop-first, ~1440px. Comfortable whitespace, information-dense enough for daily work. One dominant content area + secondary panels.

## Avoid

Dark mode. Glassmorphism. Neon gradients. Consumer-social aesthetics. Empty dashboard filler.
